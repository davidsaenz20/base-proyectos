# TIPO DE PROYECTO WEB

## Propósito

Definir las características, requisitos y metodología habitual para proyectos web.

## OBJETIVO

Crear un sistema web funcional, mantenible, seguro, validado y preparado para evolucionar.

## CARACTERÍSTICAS

Un proyecto web puede incluir:

- páginas públicas;
- paneles privados;
- formularios;
- APIs;
- bases de datos;
- automatizaciones;
- integraciones externas;
- sistemas de usuarios;
- contenido dinámico.

## MÓDULOS HABITUALES

Según las necesidades del proyecto:

- IA;
- APIs;
- base de datos;
- automatización;
- seguridad;
- observabilidad;
- archivos;
- notificaciones;
- email;
- WordPress.

No todos son obligatorios.

## ARQUITECTURA

Debe definirse antes de construir.

Como mínimo:

- frontend;
- backend, si existe;
- datos;
- integraciones;
- autenticación;
- despliegue.

## REQUISITOS

Definir:

- funcionales;
- técnicos;
- seguridad;
- rendimiento;
- accesibilidad;
- mantenimiento.

## VALIDACIÓN

Comprobar:

- funcionamiento;
- navegación;
- formularios;
- integraciones;
- visualización móvil;
- rendimiento;
- seguridad;
- errores.

## DESPLIEGUE

Definir:

- dominio;
- alojamiento;
- entorno;
- configuración;
- backups;
- monitorización;
- procedimiento de recuperación.

## RIESGOS

Evaluar:

- dependencia tecnológica;
- seguridad;
- rendimiento;
- costes;
- mantenimiento;
- escalabilidad.

## REGLA

La tecnología debe adaptarse al proyecto.

No se debe construir una arquitectura más compleja de lo necesario.

## ESTADO

**Estado:** Base inicial

**Versión:** 1.0
