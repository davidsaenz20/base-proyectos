# 04 — TIPOS DE PROYECTO

Esta carpeta contiene las definiciones y metodologías específicas de cada categoría de proyecto.

Un tipo de proyecto no es un proyecto concreto.

Define las características habituales de una categoría y sirve como referencia para iniciar proyectos de ese tipo.

## Ejemplos

- Web;
- automatización;
- asistente de IA;
- aplicación;
- SaaS;
- API;
- herramienta interna;
- software;
- otros tipos que puedan aparecer en el futuro.

## Contenido

Cada tipo de proyecto podrá definir:

- objetivo habitual;
- características;
- requisitos frecuentes;
- módulos habituales;
- arquitectura habitual;
- fases relevantes;
- riesgos;
- validaciones específicas;
- decisiones habituales;
- plantillas recomendadas.

## Regla

La información debe ser reutilizable para varios proyectos del mismo tipo.

No debe contener información específica de un cliente o proyecto concreto.

## Relación con el proyecto

Cuando se crea un proyecto nuevo, se podrá seleccionar uno o varios tipos de proyecto como referencia.

El proyecto podrá adaptar o modificar la metodología cuando sus circunstancias lo requieran.

## Principio

Los tipos de proyecto permiten adaptar la metodología universal sin modificar las reglas universales.

La existencia de un tipo de proyecto no impide crear proyectos que no encajen exactamente en ninguna categoría existente.
