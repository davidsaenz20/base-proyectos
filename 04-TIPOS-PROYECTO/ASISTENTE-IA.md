# TIPO DE PROYECTO ASISTENTE IA

## Propósito

Definir la metodología específica para proyectos cuyo objetivo principal sea crear un asistente basado en inteligencia artificial.

## OBJETIVO

Crear un asistente capaz de interpretar entradas de usuarios y proporcionar respuestas o ejecutar acciones útiles de forma controlada.

## CARACTERÍSTICAS

Puede incluir:

- conversación;
- IA;
- memoria o contexto;
- bases de conocimiento;
- APIs;
- automatizaciones;
- WhatsApp;
- web;
- email;
- bases de datos.

## MÓDULOS HABITUALES

Según las necesidades:

- IA;
- N8N;
- WhatsApp;
- APIs;
- base de datos;
- automatización;
- archivos;
- notificaciones;
- seguridad;
- observabilidad.

No todos son obligatorios.

## METODOLOGÍA

### 1. Definición

Determinar:

- usuario;
- problema;
- objetivo;
- funciones;
- límites del asistente.

### 2. Diseño

Definir:

- modelo de IA;
- instrucciones;
- contexto;
- fuentes de información;
- memoria;
- herramientas;
- respuestas;
- acciones permitidas.

### 3. Construcción

Implementar el asistente y sus integraciones.

### 4. Validación

Probar:

- preguntas habituales;
- preguntas ambiguas;
- información incorrecta;
- casos fuera de alcance;
- errores;
- respuestas inesperadas.

### 5. Seguridad

Controlar:

- datos personales;
- credenciales;
- permisos;
- acciones externas;
- información que el asistente puede consultar o modificar.

### 6. Despliegue

Definir:

- canal;
- infraestructura;
- credenciales;
- monitorización;
- costes.

### 7. Mejora

Registrar errores y casos no resueltos para mejorar progresivamente el sistema.

## PRINCIPIO

El asistente no debe inventar información cuando no dispone de datos suficientes.

Debe diferenciar entre:

- información conocida;
- información obtenida mediante herramientas;
- información incierta;
- información que requiere intervención humana.

## VALIDACIÓN

El proyecto se considera correctamente validado cuando el asistente responde de forma consistente dentro de su alcance y gestiona correctamente los casos que no puede resolver.
