# 03 — PLANTILLAS

Esta carpeta contiene estructuras reutilizables para iniciar rápidamente nuevos proyectos.

Una plantilla no es un proyecto terminado.

Es una base preparada que puede copiarse y adaptarse.

## Contenido

Aquí se podrán almacenar plantillas para:

- documentación;
- estructuras de proyecto;
- workflows;
- configuraciones;
- procesos;
- checklists;
- arquitecturas repetibles;
- otros elementos reutilizables.

## Regla

Una plantilla debe ser suficientemente genérica para poder utilizarse en más de un proyecto.

No debe contener información específica de un cliente o proyecto concreto.

## Relación con módulos

Una plantilla puede utilizar uno o varios módulos.

Por ejemplo, una plantilla de automatización podría utilizar:

- N8N;
- APIs;
- IA;
- base de datos.

## Relación con tipos de proyecto

Una plantilla puede estar asociada a un tipo de proyecto, pero no debe confundirse con él.

El tipo de proyecto define las características y metodología habitual.

La plantilla proporciona una estructura reutilizable para comenzar.

## Principio

Las plantillas deben reducir trabajo repetitivo sin limitar la capacidad de adaptar el proyecto a sus necesidades reales.
