# KADENCE — MAPA DE NAVEGACIÓN OPERATIVO

## Propósito

Este documento debe funcionar como un mapa rápido para localizar las opciones de Kadence dentro del panel de WordPress.

Su objetivo es evitar búsquedas innecesarias durante la construcción de una web.

No sustituye a la documentación oficial. Las rutas deben verificarse antes de considerarlas definitivas.

---

# 1. TEMA KADENCE

## Activar el tema

Ruta habitual:

WordPress
→ Apariencia
→ Temas
→ Añadir nuevo
→ Buscar "Kadence"
→ Instalar
→ Activar

# 13. CSS

Ruta habitual:

WordPress
→ Apariencia
→ Personalizar
→ CSS adicional

El CSS debe considerarse una herramienta secundaria.

Antes de utilizar CSS:

1. comprobar configuración de Kadence;
2. comprobar configuración del bloque;
3. comprobar configuración global;
4. comprobar si existe una solución mediante Gutenberg;
5. comprobar plugins gratuitos compatibles.

Solo después utilizar CSS.

La estructura de navegación también debe contemplar:

La configuración SEO específica dependerá del plugin utilizado.

No atribuir funciones SEO a Kadence que realmente pertenezcan a WordPress o a un plugin externo.

---

# 15. PLUGINS

Los plugins no deben instalarse por defecto.

Para cada funcionalidad se debe preguntar:

> ¿Kadence o WordPress ya pueden hacerlo?

Si no:

> ¿Existe un plugin gratuito fiable?

Solo después valorar otras soluciones.

Cada plugin utilizado debe documentarse con:

- nombre;
- función;
- versión;
- configuración;
- dependencia;
- alternativas;
- impacto sobre rendimiento;
- impacto sobre mantenimiento.

---

# 16. REGLA DE RUTAS EXACTAS

Cuando se entregue una instrucción al usuario, debe utilizarse este formato:

**OBJETIVO**

Qué queremos conseguir.

**RUTA**

WordPress
→ Apariencia
→ Personalizar
→ ...

**CAMBIO**

Qué opción modificar.

**VALOR**

Qué valor utilizar.

**VERIFICACIÓN**

Qué debe observarse después.

---

# 17. CAMBIOS DE INTERFAZ

WordPress y Kadence pueden cambiar sus interfaces.

Por ello:

- no asumir que una ruta antigua sigue vigente;
- verificar la documentación actual;
- registrar cambios importantes;
- marcar rutas obsoletas;
- mantener la fuente utilizada.

Si una ruta depende de una versión concreta, indicarlo.
