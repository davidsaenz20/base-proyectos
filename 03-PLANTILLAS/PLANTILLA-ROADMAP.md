PLANTILLA DE ROADMAP

Objetivo

Definir el camino específico que seguirá el proyecto para alcanzar el resultado esperado.

El roadmap describe qué trabajo debe realizarse y en qué orden.

No controla el estado operativo del proyecto.

El estado operativo se registra exclusivamente en:

"00-CONTROL/ESTADO.md"

RELACIÓN CON EL FLUJO DE EJECUCIÓN

El roadmap es específico de cada proyecto.

El orden operativo general del proyecto está definido por:

"03-PLANTILLAS/FLUJO-EJECUCION-PROYECTO.md"

El roadmap no sustituye dicho flujo.

Cuando el proyecto requiera una fase, tarea o entregable específico, debe quedar reflejado en el roadmap.

---

RELACIÓN CON EL ESTADO

El roadmap no debe contener:

- fase actual;
- paso actual;
- porcentaje de progreso;
- siguiente acción;
- bloqueos actuales;
- última actualización.

Estos datos pertenecen exclusivamente a:

"00-CONTROL/ESTADO.md"

Esto evita duplicidades y conflictos entre documentos.

---

ADAPTACIÓN

El roadmap debe adaptarse al proyecto.

Se pueden:

- eliminar fases innecesarias;
- añadir tareas específicas;
- dividir tareas complejas;
- cambiar el orden de tareas cuando el proyecto lo requiera.

Cualquier modificación debe seguir siendo compatible con el flujo general de ejecución y con los criterios de validación establecidos.

---

REGLA

El roadmap responde a:

«¿Qué trabajo necesita realizar este proyecto y en qué orden?»

No responde a:

«¿En qué punto exacto estamos ahora?»

Esa información pertenece a "ESTADO.md".
