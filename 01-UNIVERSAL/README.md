# 01 — UNIVERSAL

Esta carpeta contiene las reglas, principios y conocimientos que son aplicables de forma general a cualquier proyecto.

Su objetivo es evitar que cada proyecto tenga que empezar desde cero.

## Contenido

Aquí se podrá documentar:

- principios generales de trabajo;
- metodología universal;
- reglas de decisión;
- criterios de validación;
- gestión de riesgos;
- seguridad general;
- documentación;
- control de cambios;
- recuperación de proyectos;
- buenas prácticas aplicables a distintos tipos de proyectos.

## Regla

El contenido de esta carpeta no debe depender de:

- un cliente concreto;
- una web concreta;
- una tecnología concreta;
- un proyecto concreto;
- un proveedor concreto.

Si una información solo sirve para un proyecto determinado, no pertenece aquí.

## Relación con otras áreas

`01-UNIVERSAL` define las reglas generales.

Los módulos contienen conocimientos especializados.

Los tipos de proyecto contienen adaptaciones metodológicas.

Los proyectos contienen la información específica de cada proyecto.

## Principio

Antes de crear una nueva regla universal se debe comprobar que realmente puede aplicarse a diferentes proyectos.

La información universal debe mantenerse independiente de las tecnologías utilizadas.
