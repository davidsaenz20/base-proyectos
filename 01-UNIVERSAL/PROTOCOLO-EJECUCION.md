# PROTOCOLO DE EJECUCIÓN

## Propósito

Definir cómo se ejecuta y se continúa cualquier proyecto utilizando BASE-PROYECTOS.

## 1. RECUPERAR EL CONTEXTO

Antes de comenzar a trabajar se debe revisar:

- estado actual;
- objetivo;
- roadmap;
- decisiones vigentes;
- bloqueos;
- documentación relevante;
- último progreso registrado.

## 2. IDENTIFICAR EL PASO ACTUAL

Siempre debe existir una única acción principal en curso.

No se deben ejecutar varias líneas de trabajo independientes sin necesidad.

## 3. EJECUTAR

Realizar únicamente el trabajo necesario para completar el paso actual.

## 4. VALIDAR

Comprobar que el resultado obtenido cumple el criterio establecido.

## 5. DOCUMENTAR

Registrar cualquier decisión, cambio o conocimiento que deba conservarse.

## 6. ACTUALIZAR EL ESTADO

Al finalizar un paso se debe actualizar el estado del proyecto y definir el siguiente paso.

## 7. CONTROL DE DESVIACIONES

Si durante el trabajo aparece una cuestión que no pertenece al paso actual:

- registrarla si es relevante;
- no cambiar automáticamente de objetivo;
- continuar con el paso actual salvo que la nueva información obligue a modificarlo.

## 8. BLOQUEOS

Si no se puede continuar:

1. identificar el bloqueo;
2. documentarlo;
3. determinar qué información o acción falta;
4. resolverlo antes de avanzar.

## 9. CAMBIOS DE PLAN

Si aparece una razón para modificar el roadmap:

1. explicar el motivo;
2. registrar la decisión;
3. registrar el cambio;
4. actualizar el roadmap;
5. continuar desde el nuevo paso.

## 10. REANUDACIÓN

Cuando se retome un proyecto después de una interrupción, no se debe comenzar desde la memoria de la conversación.

Se debe recuperar primero la documentación del proyecto y determinar:

**DÓNDE ESTAMOS → QUÉ ESTÁ HECHO → QUÉ FALTA → QUÉ TOCA AHORA**

## REGLA PRINCIPAL

La conversación puede servir como apoyo.

La documentación del proyecto es la fuente de verdad para continuar el trabajo.
