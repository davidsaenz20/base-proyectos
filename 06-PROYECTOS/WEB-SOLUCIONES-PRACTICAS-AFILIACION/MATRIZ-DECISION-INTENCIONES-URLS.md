10. REGLA PARA LAS SIGUIENTES INVESTIGACIONES

No añadir una URL a la arquitectura simplemente porque aparezca una nueva keyword.

Toda nueva oportunidad debe entrar primero en esta matriz.

Si es equivalente a una URL existente:

→ AGRUPAR

Si merece tratamiento pero no página:

→ SECCIÓN

Si está insuficientemente validada:

→ PENDIENTE

Si demuestra una necesidad independiente:

→ CREAR

Si una modalidad, categoría o subtema demuestra una intención suficientemente diferenciada:

→ puede convertirse en un cluster independiente y seguir su propia validación.

11. SIGUIENTE FASE

Una vez consolidada esta primera matriz:

1. ampliar investigación de las áreas principales;

6. revisar canibalización;
