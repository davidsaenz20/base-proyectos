# 06 — PROYECTOS

Esta carpeta contiene las instancias reales de los proyectos que se desarrollen utilizando `BASE-PROYECTOS`.

Cada proyecto tendrá su propia documentación, decisiones, arquitectura, roadmap, validaciones y evidencias.

## Regla fundamental

Un proyecto concreto no debe modificar ni contaminar el conocimiento universal de `BASE-PROYECTOS`.

La información específica de cada proyecto permanece dentro de su propia estructura.

## Estructura

Cada proyecto deberá utilizar, como mínimo:

- control;
- definición;
- decisiones;
- arquitectura;
- roadmap;
- validación;
- evidencias.

La estructura podrá ampliarse cuando el proyecto lo necesite.

## Tipos de proyecto

Un proyecto podrá utilizar uno o varios tipos definidos en:

`04-TIPOS-PROYECTO`

## Módulos

Un proyecto podrá utilizar uno o varios módulos definidos en:

`02-MODULOS`

## Plantillas

Un proyecto podrá comenzar utilizando plantillas definidas en:

`03-PLANTILLAS`

Las plantillas se adaptarán a las necesidades reales del proyecto.

## Principio

`06-PROYECTOS` contiene proyectos reales.

La base proporciona metodología, conocimiento y estructuras reutilizables.

El proyecto utiliza esos recursos sin convertirse en una copia de la base.
