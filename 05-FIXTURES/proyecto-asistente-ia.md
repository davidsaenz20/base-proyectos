# FIXTURE PROYECTO ASISTENTE IA

## Identificación

**Nombre:** Asistente IA de ejemplo

**Tipo:** Asistente IA

**Versión:** 1.0

## Objetivo

Crear un asistente capaz de responder preguntas frecuentes de un negocio y derivar los casos que no pueda resolver.

## Problema

El negocio recibe repetidamente las mismas consultas y necesita reducir el trabajo manual de atención.

## Usuario

Clientes del negocio.

## Propuesta

Un asistente conversacional que recibe preguntas, consulta la información disponible y responde según las reglas definidas.

## Flujo

1. El usuario realiza una consulta.
2. Se recibe el mensaje.
3. Se identifica la intención.
4. Se consulta el contexto disponible.
5. Se genera la respuesta.
6. Se registra la interacción.
7. Si no puede resolverla, se deriva a una persona.

## Módulos utilizados

- Asistente IA
- Automatización
- APIs
- Notificaciones
- Seguridad
- Observabilidad

## Límites

El asistente no debe:

- inventar información;
- realizar acciones no autorizadas;
- proporcionar información fuera de su alcance;
- ocultar que necesita intervención humana cuando corresponda.

## Validación

Comprobar:

- preguntas habituales;
- preguntas ambiguas;
- preguntas fuera de alcance;
- información inexistente;
- respuestas incorrectas;
- derivación a humano;
- errores de integración.
