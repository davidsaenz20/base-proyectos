# FIXTURE PROYECTO DIRECTORIO

## Identificación

**Nombre:** Directorio de ejemplo

**Tipo:** Directorio

**Versión:** 1.0

## Objetivo

Crear un directorio organizado de profesionales y servicios para facilitar que los usuarios encuentren una opción adecuada.

## Problema

La información está dispersa y el usuario necesita localizar rápidamente servicios relevantes.

## Usuario

Personas que buscan un servicio o profesional.

## Propuesta

Una plataforma con categorías, servicios, localidades y fichas de profesionales.

## Estructura

Cada ficha puede contener:

- nombre;
- servicio;
- localidad;
- descripción;
- datos de contacto;
- estado.

## Flujo

1. El usuario indica qué necesita.
2. Selecciona o identifica una localidad.
3. El sistema busca coincidencias.
4. Muestra los resultados.
5. El usuario consulta una ficha.
6. Puede contactar con el profesional.
