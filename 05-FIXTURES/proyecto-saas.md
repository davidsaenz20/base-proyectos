# FIXTURE PROYECTO SAAS

## Identificación

**Nombre:** SaaS de ejemplo

**Tipo:** SaaS

**Versión:** 1.0

## Objetivo

Crear un servicio de software online que pueda ser utilizado por múltiples clientes mediante cuentas independientes.

## Problema

El servicio necesita ofrecer una funcionalidad de forma recurrente sin que cada cliente requiera una instalación independiente.

## Usuario

Clientes que utilizan el servicio mediante una cuenta.

## Propuesta

Una aplicación web con registro, autenticación, área privada y funcionalidades específicas para cada cliente.

## Flujo

1. El usuario se registra.
2. Crea o accede a su cuenta.
3. Se autentica.
4. Accede al servicio.
5. Utiliza las funcionalidades disponibles.
6. El sistema procesa y almacena los datos.
7. El usuario obtiene el resultado.
