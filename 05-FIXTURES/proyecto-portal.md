# FIXTURE PROYECTO PORTAL

## Identificación

**Nombre:** Portal de ejemplo

**Tipo:** Portal

**Versión:** 1.0

## Objetivo

Crear una plataforma ficticia que reúna información y funcionalidades para diferentes tipos de usuarios.

## Problema

Los usuarios necesitan acceder desde un único lugar a diferentes servicios, contenidos y herramientas.

## Usuario

Usuarios registrados y visitantes.

## Propuesta

Un portal web con área pública, autenticación, área privada, contenidos y funcionalidades específicas según el usuario.

## Flujo

1. El usuario accede al portal.
2. Consulta la información pública.
3. Se registra o inicia sesión.
4. Accede a su área privada.
5. Utiliza las funcionalidades disponibles.
6. El sistema procesa la información.
7. Se muestra el resultado.
