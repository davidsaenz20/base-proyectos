# FIXTURE PROYECTO ECOMMERCE

## Identificación

**Nombre:** Ecommerce de ejemplo

**Tipo:** Ecommerce

**Versión:** 1.0

## Objetivo

Crear una tienda online ficticia que permita consultar productos y realizar un proceso de compra completo.

## Problema

El negocio necesita ofrecer sus productos mediante un canal de venta online.

## Usuario

Cliente que desea consultar y comprar productos.

## Propuesta

Una tienda online con catálogo, carrito, checkout, pago y gestión de pedidos.

## Flujo

1. El usuario accede a la tienda.
2. Consulta el catálogo.
3. Selecciona un producto.
4. Añade el producto al carrito.
5. Revisa el pedido.
6. Completa el checkout.
7. Realiza el pago.
8. Recibe la confirmación.
9. El pedido pasa a gestión.
