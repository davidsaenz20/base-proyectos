# 05 — FIXTURES

Esta carpeta contiene ejemplos, casos de prueba y proyectos ficticios utilizados para comprobar que la metodología y las estructuras de `BASE-PROYECTOS` funcionan correctamente.

Los fixtures sirven como entornos controlados para probar el sistema antes de aplicarlo a proyectos reales.

## Contenido

Aquí se podrán almacenar:

- proyectos ficticios;
- casos de prueba;
- ejemplos de uso;
- escenarios de prueba;
- configuraciones de ejemplo;
- pruebas de diferentes tipos de proyecto;
- pruebas de combinación de módulos.
