# 00 — CONTROL

Esta carpeta contiene el estado operativo del proyecto.

Su función es permitir recuperar rápidamente el estado actual sin necesidad de revisar toda la documentación histórica.

## Contenido

Aquí se almacenará la información necesaria para saber:

- qué proyecto es;
- qué objetivo tiene;
- en qué estado se encuentra;
- en qué fase está;
- qué paso está activo;
- qué está completado;
- qué está pendiente;
- qué está bloqueado;
- cuál es el siguiente paso.

## Regla

`00-CONTROL` no contiene investigación extensa ni conocimiento técnico general.

Debe contener únicamente información de control y estado.

## Principio

Una persona o agente que abra esta carpeta debe poder comprender rápidamente dónde está el proyecto y qué debe hacerse a continuación.

## Fuente de verdad

El estado registrado aquí debe mantenerse actualizado durante toda la vida del proyecto.
