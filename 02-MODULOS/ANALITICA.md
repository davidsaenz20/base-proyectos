# MÓDULO DE ANALÍTICA

## Propósito

Definir el conocimiento reutilizable necesario para medir el uso, comportamiento, rendimiento y resultados de un proyecto.

## Qué es

La analítica permite recopilar y analizar datos sobre el funcionamiento de un sistema y sobre la interacción de sus usuarios.

Debe servir para tomar decisiones, no simplemente para acumular datos.

## Cuándo utilizarlo

Cuando el proyecto necesite conocer:

- visitas;
- usuarios;
- acciones;
- conversiones;
- errores;
- rendimiento;
- resultados de negocio.

## Cuándo no utilizarlo

No debe incorporarse analítica innecesaria cuando no exista una decisión concreta que dependa de los datos obtenidos.

## Métricas

Definir únicamente métricas relevantes para el proyecto.

Pueden incluir:

- usuarios;
- sesiones;
- eventos;
- conversiones;
- tasa de conversión;
- abandono;
- ingresos;
- errores;
- tiempo de respuesta.

## Eventos

Cada evento debe definir:

- nombre;
- origen;
- momento;
- datos registrados;
- finalidad.

## Datos

Determinar:

- qué datos se recopilan;
- por qué se recopilan;
- dónde se almacenan;
- durante cuánto tiempo;
- quién puede acceder.

## Privacidad

Evitar recopilar datos personales innecesarios.

Cuando existan datos personales, deberán aplicarse las medidas legales y técnicas correspondientes.

## Integraciones

Puede conectarse con:

- web;
- aplicaciones;
- APIs;
- bases de datos;
- herramientas externas;
- sistemas de marketing;
- sistemas de ventas.

## Validación

Comprobar:

- que los eventos se registran correctamente;
- que no existen duplicados;
- que los datos son coherentes;
- que las métricas representan realmente lo que se quiere medir;
- que los informes pueden interpretarse correctamente.

## Riesgos

- datos incorrectos;
- eventos duplicados;
- pérdida de información;
- métricas mal definidas;
- recopilación excesiva de datos;
- problemas de privacidad.

## Costes

Evaluar:

- herramienta utilizada;
- volumen de datos;
- almacenamiento;
- procesamiento;
- servicios externos.

## Dependencias

Puede relacionarse con:

- web;
- base de datos;
- APIs;
- automatización;
- IA;
- observabilidad;
- seguridad.
