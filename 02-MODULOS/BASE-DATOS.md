# MÓDULO BASE DE DATOS

## Propósito

Definir la capacidad reutilizable para almacenar, consultar y gestionar datos de un proyecto.

## FUNCIÓN

Una base de datos permite:

- almacenar información;
- consultar información;
- modificar información;
- relacionar datos;
- conservar el estado de un sistema.

## PRINCIPIO

La base de datos debe elegirse según las necesidades reales del proyecto.

No se debe imponer una tecnología concreta sin analizar:

- volumen;
- estructura de datos;
- concurrencia;
- rendimiento;
- seguridad;
- costes;
- escalabilidad;
- mantenimiento.

## DATOS

Antes de crear la estructura se debe identificar:

- qué datos existen;
- de dónde proceden;
- quién los utiliza;
- cuánto tiempo deben conservarse;
- qué relaciones existen.

## OPERACIONES

Las operaciones principales pueden incluir:

- crear;
- consultar;
- actualizar;
- eliminar;
- buscar;
- relacionar.

## SEGURIDAD

Se deben controlar:

- autenticación;
- autorización;
- permisos;
- credenciales;
- acceso a datos sensibles;
- copias de seguridad.
