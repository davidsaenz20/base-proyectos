# MÓDULO WORDPRESS

## Propósito

Definir la capacidad reutilizable para utilizar WordPress como plataforma de proyectos web.

## FUNCIÓN

WordPress puede utilizarse para:

- webs corporativas;
- blogs;
- directorios;
- sistemas de contenidos;
- webs locales;
- páginas automatizadas;
- proyectos con integraciones externas.

## PRINCIPIO

WordPress es una opción tecnológica.

No debe imponerse cuando otra tecnología sea más adecuada.

## COMPONENTES

Un proyecto WordPress puede incluir:

- WordPress;
- tema;
- plugins;
- base de datos;
- APIs;
- automatizaciones;
- servicios externos.
