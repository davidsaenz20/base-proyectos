
# MÓDULO ARCHIVOS

## Propósito

Definir la capacidad reutilizable para gestionar archivos dentro de un proyecto.

## FUNCIÓN

Permitir:

- recibir archivos;
- almacenar archivos;
- procesar archivos;
- generar archivos;
- transformar formatos;
- recuperar archivos.

## TIPOS

Puede trabajar con:

- documentos;
- imágenes;
- audio;
- vídeo;
- hojas de cálculo;
- archivos comprimidos;
- otros formatos necesarios.
